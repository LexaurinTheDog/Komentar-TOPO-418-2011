# Komentář k zákonu č. 418/2011 Sb., o trestní odpovědnosti právnických osob (TOPO)

Odborný komentář k **zákonu č. 418/2011 Sb., o trestní odpovědnosti právnických osob a řízení proti nim** — předpisu, který prolomil zásadu *societas delinquere non potest* a zavedl do českého práva pravou trestní odpovědnost korporací. Konsolidované znění k **1. lednu 2026** (dokument e-Sbírky `SB-2011-00418_2026-01-01`).

## Rozsah

- **49 paragrafových jednotek** (§ 1–48 vč. § 20a, 22a, 26a, 29a, 33a, 36a, 37a) ve 2 kapitolách
